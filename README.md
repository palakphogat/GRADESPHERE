GRADESPHERE – Student Result Management System

**GRADESPHERE** is a PL/SQL-based Student Result Management System designed to simplify the process of managing student academic records and calculating examination results.

The project automates result calculation, percentage generation, and grade assignment using Oracle PL/SQL concepts.

Project Overview

The main objective of GRADESPHERE is to maintain student records efficiently and reduce manual effort in calculating academic results.

It stores student details, subject marks, total marks, percentages, and grades in a structured database.

Features

- **Student Record Management:** Store student IDs, names, courses, and marks.
- **Automatic Result Calculation:** Calculate total marks and percentages.
- **Grade Generation:** Automatically assign grades based on percentage.
- **Update Student Marks:** Modify existing student marks.
- **Delete Student Records:** Remove student records when required.
- **Display Results:** View student results in an organized format.
- **Exception Handling:** Handle errors such as missing student records.
- **Cursor Implementation:** Display student results using PL/SQL cursors.

How to Run the Project

1. Install and open Oracle Database or an Oracle SQL environment.
